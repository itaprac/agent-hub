# Product

## Register

product

## Users

Operators of coding agents who maintain shared skills and instructions across trusted personal machines. They use the interface during focused maintenance work and need to understand repository and deployment state quickly.

## Product Purpose

agent-hub is the source-of-truth console for agent skills, instructions, machine state, and synchronization. Success means that an operator can inspect drift, edit managed content, and apply or synchronize changes without losing work or guessing what happened.

## Brand Personality

Precise, calm, technical. The interface should feel trustworthy and compact, with familiar controls and direct operational language.

## Anti-references

Avoid generic SaaS dashboards, decorative terminal cosplay, neon-on-black AI tooling, glassmorphism, metric-heavy hero layouts, and visual effects that compete with repository state.

## Design Principles

- Show real state and exact consequences before an operation runs.
- Make destructive and remote actions deliberate and recoverable.
- Keep the interface dense, predictable, and keyboard-friendly.
- Use one consistent vocabulary across CLI, API, and UI.
- Prefer visible evidence over decorative status indicators.

## Accessibility & Inclusion

Meet WCAG 2.2 AA for contrast, semantics, focus, keyboard operation, and target sizing. Support reduced motion, Light, Dark, Black, and System appearance, text scaling, and narrow viewports without hiding essential controls.
